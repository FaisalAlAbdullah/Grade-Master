# Grade-Master
It is a project written in assembly code for Intel 8086
It has 6 features 
  Add student,
  Total and percentage calculation,
  Grade calculation,
  Search for students(also can do partial searches with first few digits of the id),
  Update student info,
  can find highest and lowest among all the scores, 
rest of the instructions you'll get running the code, 
and obviously you'll need emu8086 to run it :)
